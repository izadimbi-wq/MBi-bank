# مدیریت پرتفوی — نسخه 2

این پروژه یک اپلیکیشن اندروید فارسی برای مدیریت و ثبت اطلاعات پرتفوی است.

## داده مبنا
اطلاعات اولیه از فایل Portfolio-export.xlsx کاربر استخراج شده و در:
`app/src/main/assets/portfolio_seed.json`
قرار گرفته است.

## امکانات نسخه 2
- داشبورد دارایی کل، ارزش پرتفوی، نقدینگی، سود امروز و سود پرتفوی
- نمایش نماد، تعداد، سهام جایزه، حق تقدم، قیمت، ارزش، سود/زیان و سود مجامع
- گزارش‌های پایه
- ساختار آماده برای ثبت خرید، فروش، سهام جایزه و سود مجمع
- بدون اتصال معاملاتی به کارگزاری

## ساخت APK
پروژه را در Android Studio باز کنید و از مسیر:
Build > Build APK(s)
فایل APK را بسازید.
